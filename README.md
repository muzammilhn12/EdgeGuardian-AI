# EdgeGuardian-AI
EdgeGuardian AI: Snapdragon-powered HP PC driver safety assistant. Integrates ESP32+MPU6050 sensor data with laptop camera computer vision. Classifies safety states with high accuracy, reducing false alarms. Privacy-first, low-latency, offline-capable, on-device AI using Qualcomm AI Hub/ONNX for Snapdragon NPU/CPU.
